# Reporting sensitive problems

Do not attach ROMs, saves, game assets, private keys, account tokens or full memory
dumps to public issues. Logs and captures can expose local paths and player names;
review them before sharing.

Report ordinary crashes through the bug-report template. For a vulnerability that
could expose user data or execute unintended code, contact the maintainer privately
before posting details. This development project has no guaranteed response time.

Only the current development branch is maintained. Installation checks, hashes
and rollback tests reduce accidental damage; they are not a security sandbox.
