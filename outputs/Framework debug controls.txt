SOULS CHARACTER FRAMEWORK - DEBUG VIEW

Installed version: 0.4.2 (Mario selected). Debug starts off.

F8: turn debug on/off
F9: cycle Combat / Terrain / Objects / All
F10: show through walls / respect occlusion
F6: Mario/native character toggle, unchanged

Combat shows live body capsules, active attack reach, eligible contact samples
and confirmed impact points. Terrain shows nearby cached collision triangles.
Objects shows loaded object origins. Colors and limits are explained on screen.

The view works with Mario both on and off, so you can compare body sizes.
Attack shapes linger for 650 milliseconds, labeled RECENT during that time.
It does not enable invincibility or change combat, movement, health or stamina.

Limits: these body capsules are not exact per-bone hurtboxes. Native enemy weapon
hitboxes and arbitrary object bounds are not yet mapped. Terrain is the guest
collision cache; native dynamic barriers are represented by local contact normals
when touched. Object markers identify origins, not complete object geometry.

Tested on Mario QA: views and toggles, native/Mario body comparison, a real hollow
hit (44 HP to 0), bonfire menu and return, overlay off, free jump, normal save/quit.
The game was left closed. Other saves were not loaded.
