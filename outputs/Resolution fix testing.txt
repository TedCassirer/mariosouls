Save and close Dark Souls. Run "Install Mario resolution fix.cmd" from this
outputs folder, then start the game normally. The installer verifies the tested
build, refuses an open game and backs up the currently installed files.
Includes the earlier cannon aiming and Mario-class automatic loading fixes.

Try on your test character:
1. Load at your preferred resolution. Mario should appear without changing to 720p.
2. Change resolution and reload if the game's display setting requires it.
3. Check that walls obscure Mario and prompts/subtitles stay in front of him.
4. If using the cannon, check the sight and prompt remain centered.

Synthetic D3D9 graphics checks cover 720p, 1080p, 1440p, 4K and 800x600,
with different internal scene and output sizes. These do not certify each
resolution inside Dark Souls or third-party graphics mods.

scene/UI sizes when composition succeeds. Note the resolution and window mode.
