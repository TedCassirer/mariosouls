# Historical development workspace

Active gameplay development is in [framework/](../framework/README.md).

The tracked files here preserve the original prototype, investigation scripts
and test history. Many scripts target older versions or contain local paths.
Do not treat them as an installation guide or continue gameplay implementation
here.

Ignored directories also hold dependencies, build products, extracted assets and
private backups. Do not delete this directory or run `git clean -fdx` on a prepared
workspace. See [checkpoint recovery](../docs/CHECKPOINTS.md).
