# Local helpers and historical notes

These files were created while developing and testing MarioSouls on the original
machine. They include controls, measurements, checkpoint restore commands and
installers tied to private build files.

They are preserved for local recovery, not offered as a public mod download.
A fresh clone does not contain their required binaries, caches or backup archives.
Some notes describe older behavior.

Start with the [player guide](../docs/PLAYING.md) or
[development setup](../docs/DEVELOPMENT.md). See
[Git history and installation backups](../docs/RECOVERY.md) before using restore tools.
